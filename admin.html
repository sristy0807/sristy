Connect to GitHub

The dashboard edits your site by saving files to the sristy0807/sristy repo. It needs a GitHub access token, which is only sent to GitHub.

  1. Open github.com → Settings → Fine-grained tokens → Generate new token.
  2. Name it "Site dashboard". Repository access: Only select repositories → sristy only. Set an expiry (90 days is fine).
  3. Permissions: Contents → Read and write, Actions → Read and write.
  4. Generate, copy the token and paste it here.

You stay signed in until you close this tab. The token is never saved on the device, so the games on this site can't read it.
